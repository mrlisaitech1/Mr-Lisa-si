# MR LISA SI × LISTRAYL

Next.js website prepared for Vercel with crawlable SEO pages, sitemap, robots.txt, Person structured data for MR LISA SI and Organization structured data for LISTRAYL.

## Before deployment
If your final Vercel URL is NOT `https://mrlisasi.vercel.app`, replace that URL in:
- `app/layout.tsx`
- `app/sitemap.ts`
- `app/robots.ts`

Then run `npm install` and `npm run build`.
